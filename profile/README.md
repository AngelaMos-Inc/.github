### 01 — education

**CertGames** &nbsp;·&nbsp; [certgames.com](https://certgames.com)

Gamified cybersecurity certification training. Practice questions, hands-on labs,
personalized roadmaps, and a resume builder, built so people do not quit before
the offer lands.

### 02 — research

**Lisdex** &nbsp;·&nbsp; [lisdex.sh](https://lisdex.sh)

Independent malware analysis and investigations, published in full. Delivery chains
reconstructed, operator infrastructure assessed, detection rules shipped alongside
the findings, plus the OSINT tooling the work runs on.

### 03 — tooling

**Internals** &nbsp;·&nbsp; [angelamos.com/index](https://angelamos.com/index)

Security tools built for our own work and left installable. Every one sets itself up
with a single command regardless of dependencies, operating system, or complexity.

```sh
curl -fsSL https://angelamos.com/<tool>/install.sh | bash
```
